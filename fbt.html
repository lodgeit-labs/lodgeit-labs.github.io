Fringe Benefits Tax available

Taxable value of a fringe benefit under FBTAA 1986, across nineteen benefit-category calculators — car, loan, debt waiver, expense payment, property, residual, housing, LAFHA, board, entertainment and car parking. Each returns the grossed-up figure and the FBT payable, with the intermediate workings that produced them.

Unlike depreciation and div7a, FBT is not one endpoint. It is a family of per-benefit-category calculators: the calculator URN selects the benefit category and, with it, the input schema. You enumerate the family from discovery rather than hardcoding it, and you read each calculator's input schema before calling it — the request bodies are not interchangeable across categories.

Endpoint

POST /v1/calculators/{calculator_uri}/urn:sbrm:period:fbt:fy2026

Period-scoped to the FBT year. The {calculator_uri} is one of the nineteen benefit categories below; the period URN selects the FY2026 statutory rate tables. Supplying a period the calculator does not accept returns 404, and the body names the periods it does accept.

Input

Each calculator's request body differs by benefit category. The input schema reference returned by GET /v1/calculators — and the full schema in /openapi.json — is authoritative for the calculator you are calling. Do not assume a shared request shape across categories.

Read the schema before you call. A car operating-cost benefit takes businessUsePercentage, formOfFinance and the vehicle's cost and dates; a loan takes interestChargedByEmployer and otherwiseDeductiblePercentage; a 12-week register meal-entertainment benefit takes registerPercentage. They are not interchangeable.

Worked example

A car fringe benefit under the operating-cost method: 75% business use, owned vehicle costing $40,000 acquired 1 July 2023, held the full FBT year (365 days), $3,000 fuel/repairs/servicing, $1,500 registration/insurance, $200 employee contribution:

curl -s -X POST \
  "$BASE/v1/calculators/urn:sbrm:calculator:fbt:car-operating-cost/urn:sbrm:period:fbt:fy2026" \
  -H "Content-Type: application/json" \
  -d '{
    "businessUsePercentage": 75,
    "formOfFinance": "owned",
    "acquisitionCost": 40000,
    "acquisitionDate": "2023-07-01",
    "daysHeldInFBTYear": 365,
    "fuelRepairsServicing": 3000,
    "registrationInsurance": 1500,
    "employeeContribution": 200
  }'
{
  "taxable_value": "2972.86",
  "fbt_type": "Type 2",
  "gross_up_factor": "1.8868",
  "grossed_up_taxable_value": "5609.19",
  "fbt_payable": "2636.32",
  "business_use_percentage_clamped": "75",
  "business_use_reduction": "9518.57",
  "deemed_total": "8191.43",
  "employee_contribution": "200.00",
  "operating_expenses_total": "12691.43",
  "no_private_use_reduction": "0.00",
  "taxable_value_before_operating": "3172.86",
  "taxable_value_net_operating_pre_clamp": "2972.86",
  "counts_towards_fbt_cap": true,
  "trace": { "deemed_depreciation": "6091.19", "deemed_interest": "2100.24", "deemed_total": "8191.43", ... },
  "manifest": {
    "rate_table_uris": [{
      "uri": "urn:sbrm:rate:fbt:fy2026:deemed-depreciation-rates",
      "content_hash": "4d3a9e54d740de8df7961758d8f588cf76d3a37a638075b82b2811ddb3ad95df",
      "hash_algorithm": "sha256"
    }, ... ]
  },
  "advisory": { ... }
}

Reading it back: the deemed running cost ($8,191.43) plus the actual operating costs bring the operating-expenses total to $12,691.43; the 75% business-use reduction ($9,518.57) and the $200 employee contribution reduce it to a taxable value of $2,972.86; grossed up at the Type 2 factor of 1.8868 that is $5,609.19, and FBT payable at the 47% rate is $2,636.32.

Output fields

taxable_value
The taxable value of the benefit, before gross-up.
fbt_type
Type 1 (employer entitled to a GST input tax credit) or Type 2. Selects the gross-up factor.
gross_up_factor
The statutory gross-up factor applied — 2.0802 for Type 1, 1.8868 for Type 2 in FY2026.
grossed_up_taxable_value
The taxable value grossed up by the factor.
fbt_payable
The FBT payable on the grossed-up value at the FBT rate.
the workings
The intermediate figures that produced the result — for this calculator, deemed_total, business_use_reduction, operating_expenses_total, employee_contribution and the deemed depreciation and interest under trace. They vary by benefit category.

Refusals

A request that is malformed or incomplete is refused at the gateway on the schema; a request that names a period the calculator does not accept is refused with the periods it does accept. The body names the field or the reason:

// a required field for this calculator omitted (formOfFinance)
422  {"detail":[{"type":"missing","loc":["formOfFinance"],"msg":"Field required"}]}

// a period this calculator does not accept
404  {"detail":"period_uri='urn:sbrm:period:div7a:fy2026' is not supported by calculator 'urn:sbrm:calculator:fbt:car-operating-cost'. Supported: ['urn:sbrm:period:fbt:fy2026']"}

Notes for integrators

  • Money, rates and the percentage echoes are returned as decimal strings, not JSON floats — "2972.86", "1.8868", not 2972.86. Parse accordingly.
  • The grossed-up trio and the intermediate workings are surfaced at the top level of the response, alongside taxable_value; the per-benefit deemed figures sit under trace.
  • manifest.rate_table_uris is non-empty here and carries a content hash for each FY2026 rate table the calculation consumed — you can pin against them and detect a rate-table change.
  • Enumerate the calculators from GET /v1/calculators; do not assume a shared request shape across benefit categories.
